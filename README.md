# BARE — React + Vite landing page

## Requirements
- Node.js 18+ (recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Project structure

```text
bare-react-vite/
├── index.html
├── package.json
├── vite.config.js
├── README.md
└── src/
    ├── App.jsx
    ├── main.jsx
    └── style.css
```

This is a frontend demo. Product details, prices, customer reviews, contact details, cart persistence,
authentication, checkout, payments, admin tools and backend integrations are placeholders/not connected.
Replace sample product content and imagery with BARE-approved assets before launch.
